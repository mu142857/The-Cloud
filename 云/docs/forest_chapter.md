# 森林章节（木星）实现设计

剧本来源：剧情姐《云层之中的大象》第一章「木星森林」，纯文本在
`/private/tmp/claude-501/-Users-jiamulin-Desktop---programs-----The-Cloud/6b1089f0-29dd-4f5c-9a65-79164258b28e/scratchpad/story/story.txt`（开头到「二、妮芙的三分钟」之前）。
**以剧情姐为准**：她写的对白原样用；小说式旁白（「晨看着……不知道该接什么」）不进游戏，改成画面/动作或删掉。
作者要求：对话越多越好；先写中文，英文以后统一翻译（`en` 先留空，引擎回落到中文）。

## 硬规矩（所有人）

- 零门槛艺术作品，**不是小游戏合集**：没有失败、没有计时、没有操作考验。剧本里所有「【小游戏位置】」一律改成**轻解谜 / 互动**：走过去、点一下、选对东西（选错只会被弥洛吐槽，然后再选）。听声音的地方**一定同时有画面提示**（不戴耳机也能玩）。
- 晨的动画永远 100ms 一帧，不许用 speed_scale 加速任何角色动画；快慢只改移动速度。
- 画面：晨最亮，背景暗；森林身份色绿/青绿；硬边像素、alpha 0/255（特效可半透明）、不描边、不用纯黑。
- 开场和晨一起坠毁的外星人同伴（Alien 节点）在森林里**不出现**（那套图以后是河边的泥芙）：坠毁动画只甩出晨。代码保留，只是不用。
- 鹿 = 现有 `npc_deer.gd`；弥洛 = 现有蛇女 `npc_snake.gd`（有尾巴，剧本里「用尾巴推过来一把椅子」）。弥洛移动时就是播 idle 平移（蛇滑行）。
- 不要 git commit；不要改任何 Bilibili Toy 使用手册。Godot 命令用 lockf 包着、静音（见各 brief）。

## 节拍（flags 按顺序）

0. **坠毁**（已有动画，去掉同伴）→ 晨爬起来：「啊……糟糕……坠毁了。早知道就给飞船买上保险了。」
   试着把零件往船上装（可选互动 wreck：两三句、换位置都不对）。
1. **坠毁现场**：
   - 发光木头（已有拾取过场）：「太好了，有了这个，飞船就能再次起飞了。」燃烧值 10→60，「启动所需：200」，晨：「……再找一点。」
   - 行李（luggage）：拿到私人物品 —— 大象的画、物种查询结果、通勤卡、母星照片、音乐盒（附朋友纸条）、地图。描述文字用剧本原文。
   - 三样普通材料（scrap 50 / resin 40 / branch 50）：10+50+50+40+50 = 200。
   - flag `fuel_full`：燃烧值到 200 → 晨提示可以试着启动（飞船上出现小箭头）。
2. **启动失败**（互动 wreck，要求 fuel_full）：引擎尝试的声音→画面字「推进器损坏」→ 晨：「你能不能一次说完。」→ 鹿出现在 deer_appear：「它掉下来以前就坏了。」…→ 晨拿出画 → 「是大象，旧路那边有。」「跟我来。」→ 鹿往右跑。flag `deer_met`。
3. **旧路**（鹿带路：鹿跑到下一个点、停下、回头看晨；晨走近才跑下一段）：
   - stall：鹿介绍「这里以前卖吃的……」（晨记日记 → 鹿走慢一点）。
   - 鹿口中的大象在变：分三处说（鼻子很长 → 离得太远 → 只看到背影）。
   - **轻解谜 1 倒木**（log）：鹿：从这里更近。晨要拖开下面两根较轻的树枝（两个互动点，点一下晨就拖开一根），然后鹿顶住倒木，倒木滚开/压低。
   - **轻解谜 2 雾里找路**：鹿先说「往这边。别去水声最响的地方，那里下面是空的。」然后钻进树丛不见。雾变浓。线索同时有声音和画面：鹿角敲树两下（声音从布条方向来，左右声道）、地上的蹄印、树枝上的布条（布条会被风吹动一下）。在 cloth 互动 = 拐进树丛 → 淡出 → 树屋外。走过头到 hollow：水声变很响，晨自己停下：「水声好响……」并往回退几步（不惩罚）。
4. **树屋外**：屋里的声音「你这次又跟人说自己见过了？」鹿不接话、低头拨角上的布。晨把材料放门口，问能不能修飞船。→ 进室内。
5. **树屋室内**（弥洛）：剧本原文对话（不能 / 坏的那块呢 / 你站那么远 / 便宜燃料 / 坐，别用那把）。可互动的东西各有一两句：挂姓名牌的收音机、自己转的路标、换过椅脚的椅子、小碟子。烧水：两个杯子，「喝不喝？」「烫。」
   - **轻解谜 3 递工具**：桌上三把工具，弥洛要「旁边那把」；选错她吐槽一句，再选。
   - **轻解谜 4 听管道**：墙上三段管道，点一段就听一段（清脆 / 发闷 / 细小尖响），**漏气那段同时会冒一丝细白汽**。选中漏气那段 → 晨来拧（「手还在往反方向拧」的对白）→ 修好。flag `ship_fixed`（推进器修好）。
6. **留声机和音乐盒**：留声机响几个音卡住；晨拿出音乐盒，弥洛清碎屑，旋律走下去。「声音会变。」（音乐盒物品描述更新）
7. **送水泵**：屋外鹿的脚步声。弥洛带上水泵，三个人一起走到 empty_house：敲两下门、没人；弥洛把水泵挪到淋不到雨的地方；门槛上的灰、旁边早放好的另一件东西（可互动看一眼）。走到 shop：碰门，「饼难吃，太甜」「要你管」，鹿：「她又想那个人了。」
8. **坡地**（slope）：弥洛先回树屋（滑走）。凹陷 + 浓雾。鹿说出真相（妈妈、讲多了就成了见过、「我要是说不知道，你还会跟我来吗？」）。可选互动：凹陷 → 晨画进日记「还不知道是什么」（鹿等着，不补充）。之后走回树屋门口进屋。
9. **树屋室内·再访**：留声机换了零件（「旧的实在不能用了。」）→ 旋律越过卡住的地方 → 那个人的故事（吵架、走了）→ 透明种子 + 叮嘱（物品：种子、弥洛的纸条）→ 告别（「没长出来，也不是不能来。」）。
10. **回飞船**：淡出淡入到坠毁现场，鹿在飞船旁：「不知道。我只认得这里的路。」→ 互动飞船起飞 → 起飞过场 → 章节结束卡（「未完待续」，以后接飞行段）。

再次和 NPC 说话（主线之外）要有闲聊句（每个阶段 1~3 句），作者要的是「对话更多更好」。

## 剧本数据格式 `data/story_forest.json`

```json
{
  "speakers": {"chen": {"zh": "晨", "en": "Chen"}, "deer": {"zh": "鹿", "en": "Deer"}, "miluo": {"zh": "弥洛", "en": "Milo"}, "voice": {"zh": "屋里的声音", "en": "A voice inside"}},
  "markers": {"wreck": 120, "...": 0},
  "hotspots": [
    {"id": "wreck_tinker", "at": "wreck", "room": "forest", "label": {"zh": "飞船", "en": "Ship"},
     "need": ["crashed"], "not": ["fuel_full"], "once": false, "scene": "wreck_tinker"}
  ],
  "scenes": {
    "wreck_tinker": [
      {"say": "chen", "zh": "……", "en": ""},
      {"do": "flag", "set": "tried_parts"}
    ]
  }
}
```

hotspot：`at` = marker 名或数字 x；`room` = `forest` 或 `treehouse`；`need` 全部满足、`not` 全都没有才出现；同一位置多个 hotspot 时取列表里第一个满足条件的；`once` 用完就消失；`sprite`（可选）= 这个点要画的图（res:// 路径），`hide_after`（可选 flag）= 这个 flag 之后图也隐藏。

scene 里的步骤（引擎全部要支持，剧本只用这些）：

| 步骤 | 意思 |
|---|---|
| `{"say": who, "zh", "en"}` | 说话人头顶的对话框，打字效果，按确认 / 点击继续 |
| `{"narr": {"zh","en"}}` | 屏幕中下方一行小字（系统提示，如「推进器损坏」「启动所需：200」）|
| `{"do": "walk", "who", "to"}` | 走到 marker / x（晨用 auto_dir；鹿用 run_to；弥洛滑过去）；等走到再下一步 |
| `{"do": "face", "who", "to"}` | 转向某人或 marker |
| `{"do": "wait", "sec"}` | 停一会 |
| `{"do": "show", "who"}` / `{"do": "hide", "who"}` | 出现 / 消失（可带 `"at"`）|
| `{"do": "give", "item"}` / `{"do": "take", "item"}` | 进 / 出背包（进背包有拾取小动画和提示）|
| `{"do": "flag", "set"}` | 设 flag |
| `{"do": "journal", "zh", "en"}` | 日记加一条（日记是背包里的一个私人物品，详情里能翻到所有条目）|
| `{"do": "sfx", "name", "pan"?}` | 播音效（`pan` -1..1 左右声道）|
| `{"do": "fade_to", "room", "at"}` | 黑屏淡出、换到房间/位置、淡入（同行的 NPC 一起带过去：`"with": ["deer"]`）|
| `{"do": "anim", "who", "name"}` | 播角色一段动画（如 deer graze / look）|
| `{"do": "prop", "id", "state"}` | 场景物件换状态（倒木 moved、水泵 placed、留声机 new、管道 fixed 等）|
| `{"do": "guide", "to"}` | 鹿带路模式：跑到 marker 停下回头等，晨走到离它 60 以内才算到 |
| `{"do": "goto", "scene"}` | 接着播另一个 scene |
| `{"do": "pick", "options": [{"id","label":{zh,en},"scene"}...]}` | 让玩家点选场景里的东西（递工具、听管道用）；每个选项跳到自己的 scene |
| `{"do": "end_chapter"}` | 章节结束卡 |

## 补充步骤（第二版，剧本和引擎都要用）

| 写法 | 意思 |
|---|---|
| hotspot 加 `"trigger": "enter"` | 晨走进范围（`"range"`，默认 20）就自动触发，不用按键（塌陷口 hollow 用）|
| walk / guide 加 `"wait": false` | 不等走到就接着下一步（几个人同时走：先发两个 `wait:false`，最后一个正常 walk 等）|
| walk 加 `"speed": 数字` | 这一次移动的速度（鹿「走慢一点」用；不改动画帧速）|
| `{"do": "ambient", "name", "at", "on": true/false}` | 在某个 marker 放一个循环环境声：音量随晨的距离变化、左右声道随方位（雾里的鹿角敲树、塌陷口的水声）；`on: false` 关掉 |
| `{"do": "show_item", "item", "sec"?}` | 晨把一件物品举起来给人看：物品图标出现在晨头顶前方，直到下一句说完或 sec 秒 |
| `{"do": "if", "flag", "then": scene, "else": scene}` | 条件分支（`flag` 可以是 `"!名字"` 表示没有）|

## 开发者模式（F8）

只在 debug 构建 / 编辑器里运行时有效（导出的正式版按 F8 没反应）。代码在 `scripts/dev_panel.gd`。

- **开关**：F8 打开 / 关上右边的小面板。游戏照常跑；面板不抢晨的移动键——用鼠标点，或者按 1~4 / Tab 切换页签（面板开着时 Tab 不开背包）。
- **1 节拍**：按章（森林 / 飞行一 / 河流篇）列主线大节点，每章 6~10 个（`data/dev_names.json` 的 `beats`，按 `docs/剧情简版.md` 挑），本章现在在哪一段亮黄。点一下 = 跳到那一段的开头：重新载入那一章，再跳到它前面那个 flag（和命令行 `--beat=` 同一套：flags、物品、NPC 位置、小游戏结果都补齐）；能跨章跳（去森林 = 新游戏，去飞行一 / 河流篇用 SEED，本章已经播完就带着真实状态）。**剧情播着也能跳**（对话、过场、点选、小游戏）：F8 和面板上的点击由面板最先接，旧场景整个扔掉再载入。最下面「全部节点」折叠着剧本里所有设过的 flag（细碎，调试用）。剧本改了、某个大节点前面那个 flag 变了，改 `beats` 里的 `after`。
- **2 传送**：所有 markers（按 x 排，屋里的 room_* 在最后），点一下晨就到那里；room_* 会进屋（前墙淡出），别的点会出屋。剧情在播的时候不传送。
- **3 状态**：正在播的 scene id 和第几步、晨的 x、在屋里还是屋外、现在的状态、背包；下面是所有 flag，亮的是已设，点一下设上 / 去掉。
- **4 开关**：快走（只把晨的移动 ×3，动画帧速不变）、跳过对话（每句 0.15 秒自动推进）、显示范围（marker 竖线 + 名字、能用的 hotspot 的互动范围，红色竖线 = 现在这一段的左右边）、雾开 / 关、前景层开 / 关、补写台词标蓝（剧本里带 `"added": true` 的台词正文用柔和的蓝色 #8fb8e0，剧情姐原句保持原色；debug 构建默认开，导出的正式版默认关）；按钮：重开本章（从坠毁之后开始）、给齐本章所有物品、燃料加满。
- 自测：`-- --dev_test` 把每个开关、按钮、传送点点一遍，挨个跳三章所有大节点（每个跳完自动玩到下一个大节点），再在对话 / 点选 / 小游戏 / 驾驶舱小游戏进行中真的按 F8 点按钮跳走，打印 `DEV_TEST_DONE`。

## 不推人（作者的规矩，引擎和剧本都要守）

- 不许用台词 + 自动走路把玩家推回去。走进 `trigger:"enter"` 的点触发的剧情里，引擎**不执行**「晨 walk」（`--story_check` 会列出来）。
- 没到时候的地方用看得见的东西挡：倒木没推开之前，旧路到倒木为止；塌陷口（hollow）是个坑，晨走到坑边就停住，像碰到边。左右不可见的墙附近雾会变浓（看得见的边）。

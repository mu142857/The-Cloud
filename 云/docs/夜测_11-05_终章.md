## 作者早上要决定的

1. **大象没有图。** 结局一、二里大象是一块深灰色的方块，头上还飘着英文 `elephant`（占位）。这是整部戏的落点，最显眼。
   `art/characters/` 下没有 elephant；芦苇地那边的笔记早就记着「还没有大象 NPC 图」。要画的动作：吃草、抬头、喝水、甩耳朵、转身、扯草、
   鼻子伸出去 / 举起来、走、蹭树。这个我没动（是角色美术，要你定画风和谁画）。图：`e1_大象占位色块.jpg`、`e2_饭团缺图标_大象占位.jpg`。
2. **芦苇地没有黄昏和夜里。** 剧本里结局一「黄昏，大象走上山坡」、结局二「夜里躺下 → 大象的呼吸声 → 第二天」，
   但芦苇地的 `sky` 只是剧情状态，画面一直是大白天（room.json 里写着「画面上没有东西」）。结局二最明显：大太阳底下躺下睡觉，然后出「第二天」。
   要不要给芦苇地加一层随时间变的色调？我做了张示意（只是整张乘一层颜色，游戏里没改）：`芦苇地_黄昏夜里示意.jpg`。
   你说要，我就照这个方向在 reed_field.gd 里做平滑的明暗过渡（晨不跟着暗，亮主角）。
3. **母星城市里的晨发白。** 尾声穿过城市去车站那一段，晨跑起来身子是浅灰、斗篷是肉粉色，比别处白得多。
   原因是 chen.gd 给城市配的光（冷灰染色 + 白色轮廓光 + 光晕 + 路灯光柱），注释写的是「斗篷偏冷灰」，是有意调的，所以我没改。
   你说的「城市闪回跑入的白色」如果是指这个，告诉我往哪边调（比如只去掉光柱里的提亮）。终章那次闪回（第四次）我逐帧看了，不白。
   图：`e1_城市里的晨_放大.jpg`、`e1_城市连拍.jpg`、`e2_闪回4进场连拍.jpg`。
4. **「全剧终」后面没有制作人员名单滚动。** 终章最后是「全剧终」卡，按任意键回标题。名单只在第一章奔跑时滚一遍、标题页「制作人员」里有。
   要不要在「全剧终」后面再滚一遍？
5. **飞出驾驶舱那一下是硬切。** 三个结局开头的 cockpit_dash：紫色云海一帧切成黑色星空，再黑屏进芦苇地 / 小镇。
   这是 11-02 你定的「老样子加速飞走然后黑屏切换」，和飞行一结尾同一套，所以没动；只是在终章里是往云层星「降落」，冲进黑色星空有点怪。图：`e1_降落连拍.jpg`。

### 图标一直挂着（几处一起修的）

`show_item` 不写 `sec` 时，图标要等到下一句 say 才收；有的段落举完东西就没台词了，图标就跟着晨走到下一个房间（narr 也不收）。
`data/story_final.json` 里这种 20 处：后面接的是台词的照旧，后面没台词的加 `sec: 2.5`，后面紧跟「第一页」narr 的加 `sec: 4`（narr 最长 3 秒）。

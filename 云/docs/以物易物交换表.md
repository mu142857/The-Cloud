## 现在游戏里已经有的

- **大嘴鸟**：森林林间空地的尽头。过了塌陷口上的木板桥，往信号箱右边走，它在倒木前面的树桩上。空地本来就是去拿阀门的路，但这个角落要特意走过去才会看到。
- **料理鼠妈**：高处市集右半段两根路灯之间，摆着自己的小摊：布篷、石灶、锅、碗、画着碗的木招牌。
- 两个人都能聊天，初见一段、以后一句。聊完会弹出背包选物条（最后一格是「算了」）：
  - 递了它不要的东西：它说一句，东西还在晨手里；
  - 递了特殊的东西：它另有反应。大嘴鸟对大象的画、鼠妈对饼干，都不收。
- 六笔交换都接上了；换完了，它再说一句就结束（`toucan_done` / `rat_chef_done`）。

## 交换怎么发生（机制，已经做好）

1. 聊天里 NPC 自己说想要什么、能给什么。
2. 晨从背包里选一件递过去。
3. 如果是它要的：先播它的反应台词，晨交出东西，再拿到换回来的东西（飞进背包）。
4. 记下 flag：
   - `barter_<npc>_<这一笔>`：这一笔换过了；
   - `barter_<npc>`：和这个 NPC 换过；
   - `barter_any`：换过任何一次。
5. 一笔只能换一次。可以设前置条件，比如「先换过大嘴鸟的羽毛」。也可以只给对方看一眼、东西不收走（`keep`）。
6. 自动玩和跳节拍一律选「算了」，不影响主线。

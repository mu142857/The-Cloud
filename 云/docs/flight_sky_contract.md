## 剧本不用改

- 剧本照旧用 `{"do": "prop", "id": "cockpit_window", "state": "<状态>"}`。
- 现在这些状态是长镜头上的「关键帧」：换状态 = 背景从上一个样子平滑过渡到下一个，不再硬切。
- 飞行一用到的状态，按播放顺序：
  - `forest_canopy` → `canopy_fall` → `forest_below` → `forest_far` → `turning` → `clouds`（起飞，每个之间只隔 1～2 秒）
  - `debris_wall`（改航线）
  - `clouds_fast`（烧完纪念品，加速）
  - `river_planet` → `river_city` → `clocktower` → `boats` → `tilt` → `skid`（降落，间隔 1～2 秒或者一句台词）
  - `channel` → `crate`（落水、撞箱子）
- `story_final.json` 还会用到 `yard_elephant_far` 等状态，这次不画。引擎遇到 sky.json 里没有的状态：保持当前画面，并打一次警告。

## 美术：`art/cockpit/sky/`

`sky.json`：

```json
{
  "size": [480, 270],
  "default_blend": 2.0,
  "layers": {
    "forest_trees": {"img": "forest_trees.png", "tile": true},
    "planet_small": {"img": "planet_small.png"}
  },
  "states": {
    "forest_canopy": {"blend": 1.2, "bg": ["#0d1714", "#1d2f29"], "layers": [
        {"id": "forest_trees", "y": 40, "speed": 6, "vy": 0, "alpha": 1.0}
    ]},
    "canopy_fall": {"blend": 1.0, "layers": [{"id": "forest_trees", "y": 120, "speed": 6, "vy": 20}]}
  }
}
```

每个 `layers` 条目的意思：

- `id`：引用顶层 `layers` 里的一张图。图在 `sky/` 目录下。
  - `tile: true` 的图要能横向无缝接起来，宽度 ≥ 480。
  - 不 tile 的图（星球、钟楼之类）用 `x` 定位，左上角在屏幕坐标。
- `y`：图的上沿在屏幕上的 y。
  - 可以超出 0..270。比如森林往下沉，就是 y 从 40 变到 300。
- `speed`：横向卷动，单位像素/秒。
  - 正数 = 往右卷。机头朝左，飞船往左飞，所以景物往右走。
  - 离得越远的层越慢。
- `vy`：停在这个状态时，每秒继续往下（正）或往上（负）漂多少像素。
  - 用它让画面在两个关键帧之间也一直在动，不会定住。
  - 起飞时森林一直往下沉，就靠这个。
- `alpha`：可选，默认 1。
- `bg`：可选。底色上下两端的渐变，两个颜色。
  - 换状态时，底色也在 blend 秒里平滑过渡。
- `blend`：从上一个状态过渡到这个状态要几秒。
  - 不写就用 `default_blend`。
  - 剧本里有的状态只停 1 秒，blend 要跟着短一些。

**过渡规则**（引擎实现）：
- 新旧两个状态都有的同一个 `id`：y、speed、alpha 插值过去，图本身不换。所以「森林在下面 → 更远」是同一张图在往下沉，不是换图。
- 只在新状态里有的层：淡入。只在旧状态里有的层：淡出。
- 淡入淡出用 4 档台阶（0 / 0.25 / 0.5 / 0.75 / 1），和全项目的像素淡入一致。
- 所有位置都取整到像素。

**画面要求**：
- 背景比船暗、比船低对比，船和晨要一眼看得清。规则是亮主角、暗背景。
- 颜色用森林绿 / 青绿，不用蓝。
- 河流城市是灰色鸽子笼一样的高楼。
- 起飞那段从森林开始，就是 `art/forest/` 那片林子（10-29 起直接用同一批树，见文末「起飞的森林」），玩家刚从那里飞出来。
- 至少分三层远近：远景很慢、中景、近景快。云和碎石带要有近处掠过的东西，这样才有速度感。
- 星球变大不要用非整数缩放，像素会糊。做两三张不同大小的图交叉淡入。
- 碎石：`art/cockpit/debris_*.png` 可以重画、加大。
  - 躲碎石时它们在船外飞过，要比现在窗里那种大一些。大概 12～28 像素，暗色、有一点亮边。
- 生成脚本放 `tools/`。可以扩充 `tools/cockpit_art.py`，也可以新建 `tools/sky_art.py`，要能重跑。

## 引擎

**船外背景**：
- 在驾驶舱（room = cockpit）可见时，画在飞船后面，铺满一整屏。
- 背景不跟镜头走，所以船上下挪的时候背景不动。可以用 CanvasLayer，也可以每帧对齐镜头。
- 要比屏幕大一圈，镜头抖的时候不露边。
- 原来的纯色底 `BG_C` 换成它。

**窗**：
- 有 `sky/sky.json` 就不再画 `window_<state>.png` 和占位窗景。
- 窗洞在 `cockpit_back.png` 里是透明的，直接透出背景。
- 没有 sky.json 时退回原来的做法。

**船上下挪**：
- 晨、室内、外壳、所有物件一起上下挪。最简单的做法是镜头反向偏移，背景不动。
- 平时飞行中可以有很轻的上下起伏，1 像素左右、很慢，有在飞的感觉。

**`debris_steer` 改成上下躲**：步骤格式不变，`{"do": "debris_steer", "id": "flight1_debris", "sec": 40, "fuel_per_bump": 1, "fuel_max_loss": 5}`。
- 碎石从屏幕左边（机头方向）进来，往右飞过船。
  - 每一波走「上」或「下」：贴着船身上沿，或者贴着下沿。
  - 船挪开了，碎石就从船上面或下面擦过去，看得见。
  - 没挪开就撞上：机身晃一下，一声闷响，左上角燃料少 1（整段最多扣 5），晨偶尔说一句，不锁人。
- 预告：碎石到之前约 2 秒，左边那个高度上先出现一个远远的小影子，或者一道淡淡的划痕；同时响一声。
- 操作：
  - 键盘：↑ ↓ / W S。
  - 鼠标 / 触屏：按住屏幕上半边或下半边。
  - 船的偏移范围大约 ±28 像素，按住时平滑移动。松手后船留在原位，或者很慢地回到中间。
- 不会失败，不显示倒计时。不按也照样过去，只是会撞几下。总时长照 `sec`。
- 提示文字：「↑ ↓  躲开碎石」/「↑ ↓  Dodge the debris」。第一次按键后或者 7 秒后淡出。
- 删掉：气流线、机头小三角、窗内闪光、`view_shift` 的用法。
- 保持不变：
  - `--story_auto`：自己躲，8 秒内播完。
  - 跳节拍（ff）：瞬间完成，撞 0 次。
  - `dev_skip`：F8 自测时直接做完。
  - `flight1_bumps` 写进状态。
  - `--story_check` 的燃料核对。
- 躲碎石期间，背景状态是剧本当时设的那个（clouds / debris_wall）。碎石是额外加的一层，在背景前、船后。

## 起飞的森林（10-29 作者反馈「起飞的时候森林跟正常走的森林不一样」）

原来起飞几段的 forest_far / forest_mid / forest_near 是 `sky_art.py` 另画的三角树，颜色、树形、层次都和森林关卡不一样。现在：
- 森林各层就是森林关卡那几张：`sky_art.py` 直接调 `tools/forest_art.py` 的同一套函数、同一组 seed 再画一遍
  （`art/forest/` 只读，不改它）。画布往上加高，露出原图里伸出画面上沿的树冠上半截和树尖；下面 270 行和
  `art/forest/*.png` 逐像素一样（生成时断言，`forest_art.py` 改了没重跑会报错）。
  - `forest_bg`：上面是林冠以上的天（地平线一带最亮 L≈.30，往上暗回 .19），下面接 `art/forest/sky.png` 原图（林冠的黑、雾带、光斑）。
  - `forest_ridge` / `forest_far` / `forest_midfar` / `forest_mid` / `forest_main`：对应关卡的 ridge / far / midfar / mid / main。
    关卡的 front（挡在晨前面的近黑前景）、光柱、林子里跑过的动物不用。
  - 加高出来的树冠照 forest_art 的规矩往「同一高度的背景色」里褪，树尖比林冠底少褪（远层也是读得出的树梢剪影）。
- 怎么动：`sky_art.py` 的 `forest_at(h, v, climb)`。镜头比关卡高 h 像素时，关卡里 y=0 那一行在屏幕上的 y = h × 这层的下沉比例
  （bg .55、ridge .6、far .7、midfar .8、mid .9、main 1，近的沉得快）；横向速度 = v × 关卡里这层的 scroll_scale（ridge .06 … main 1）。
  - forest_canopy h=40：刚离地，还在树干之间，船底下是关卡里那条雾带——接森林关卡起飞过场的最后一幕（船贴着树干往左飞出画面）。
  - canopy_fall h=190：穿过林冠，近处大树的枝一层层从窗边掉下去；停在这段的时间看对白长短，爬升 8 像素/秒，停 20 秒也到不了下一段的高度，不会倒回去。
  - forest_below h=380：主层树尖沉到画面下面，远处几层的树梢在船底下；forest_far 470、turning 560：森林成了脚下地平线上的一条。
  - clouds：森林的天（forest_bg）4 档淡出成云里的底色（被扫过来的云层盖住，看不出台阶），最远两层沉出画面。
- 亮度：雾带是森林关卡原样的亮度（比舱壁亮），只在开头约 2 秒的 forest_canopy / canopy_fall 里出现在船底下，没有压暗——认得出是同一片林子更要紧。
  起飞几段的底色 `bg` 两端都是 forest_bg 最上面那档的颜色（整屏都被它盖住，只在它上沿露出来）。

## 躲碎石时镜头拉远（10-30 作者：「躲避石头的时候飞船能不能缩小一点」「切远景，但不是那个跟角色一样小的那个，我觉得只是缩小」）

`debris_steer` 一开始，镜头从驾驶舱剖面拉远到船外，整艘船变小；碎石都过去以后拉回剖面，再接着播剧情。

- **船外观的图**：`art/cockpit/ship_out/ship_out_<n>.png`，n = 93 / 87 / 81 / 75 / 70 / 65 / 60 / 55（大小 %）。
  - 由 `tools/cockpit_art.py --ship_out` 生成，**只写这个目录**。注意：完整重跑 `cockpit_art.py` 会覆盖 `sky_art.py` 画的 `debris_*.png`。
  - 和 `cockpit_front.png`（1 倍那档）是同一架船、同一套颜色和破损：
    - 大块颜色 = 1 倍外壳的平涂版按像素中心取样；
    - 1 像素的细节（面板缝、接缝、雨痕、门缝、补丁、窗框、斜撑、反光、紫红条、尾翼亮边）按缩小后的坐标重画；
    - **不做非整数缩放**。
  - 外壳 / 座舱玻璃（`HULL`、`WIN_POLY`、`STRUTS`……）改了以后要重跑 `--ship_out`，再 `--headless --import`。
  - 最小只做到 0.55：0.5 倍就和森林里起飞那艘（`art/level1/ship_fly.png`）一样小了。
- **拉远的过程**（`cockpit_room.gd`「船外远景」，`far_out(k)` / `far_in()` / `far_snap()`）：
  1. 外壳 `cockpit_front.png` 在剖面上 4 档淡入，0.4 秒，像出了舱门。
  2. 1.3 秒里大小从 1 缓到 k，用 smootherstep：起步缓、停得缓。
     - 每一刻取相邻两档图交叉淡入：小的垫在下面先 4 档淡入，大的盖在上面再 4 档淡出。船身任何一刻都是实的。
     - 绕同一个点缩，最后主船身中线停在 y = 140。
  3. 同时背景的横向卷动慢下来：越快、越近的层慢得越多，最多慢 30%。镜头往后退了，景物显得远。
  - 拉回时倒着走同一条曲线。远景时室内、物件、晨都藏起来；晨的小声嘀咕从远景船的驾驶窗上方冒出来。
- **远景里的玩法**（`cockpit_debris.gd`）：
  - 船上下最多挪 40 像素（剖面里是 28），而且往上挪满时尾翼尖不高过 y = 40，上面是燃料栏。0.75 那档实际是 ±35。
  - 按住时目标每秒走 100 像素，船本身照旧用弹簧追。
  - 碎石速度 × (0.5 + 0.5 × 倍数)：0.65 倍时约 173 像素 / 秒。
  - 碎石图不缩：相对小船更大，看得更清楚。道、预告、碰撞都按远景船的轮廓（`far_hull()`）算。
  - 最后一块碎石飞走后：船先回中间（弹簧 + 光晕，0.7 秒），再拉回剖面。
  - 反重力光晕：远景船挂自己的 `ship_glow`（`set_from_texture` 当前那档图，`reach_scale` 1）。
- **参数**：
  - 剧本 `debris_steer` 可写 `"far_scale": 0.75 / 0.65 / 0.55`，不写就用 `cockpit_debris.gd` 的 `FAR_K`（0.65）；1 = 不拉远，和原来一样。
  - 命令行：`--far_scale=0.75` 临时盖过剧本；`--debris_full` 让自动玩也按真实时长和拉远速度播，截图用。
- **不变的**：
  - 不会失败；不按也能过，实测 7 波全撞，燃料最多扣 5。
  - `--story_auto` 8 秒内播完，连拉远拉回约 7.1 秒。
  - 跳节拍（ff）瞬间完成。F8 的 `dev_skip` 直接回剖面。
  - `flight1_bumps`、`--story_check` 的燃料核对照旧。

## 躲碎石改成波次 + 光晕均匀 + 起飞红光（10-30）

作者：「小游戏也乏味」「为什么最开始上升的时候没有外侧的光，我觉得红光不错」「你这个也不平均啊你的上下移动飞船的光」。

- **波次**（`cockpit_debris.gd` 的 `PLAN`，按 `sec / 40` 缩放，总长不变，约 42 秒连拉远拉回）：
  上道一块 → 下道一块 → 上道连两块 → 中间留缝的一排墙 → 上下交替三块 → 偏上的缝 → 结尾三排墙（缝下、中、上蛇形）→ 穿出去。
  - 每波有一条安全通道（船挪到哪躲得开）。墙的缝 = 船挪到那里时船身上下各留 10 像素。换道的两波至少隔 2.8 秒。
  - 找通道：预告时 `nav_beep`（碎石在上面音高、在下面音低，一排墙两声）；碎石进屏幕 `debris_pass_l` 声像偏左，过了船尾 `debris_pass_r` 偏右；
    有碎石来时一直有 `airflow_loop`（音高跟着通道高低），机头前面通道的高度上有几道很淡的气流线往船这边流。
  - 擦边（离船身不到 6 像素没碰到）：泛光闪一下 + 几颗火星 + 一声轻的 `ship_whoosh`。
  - 撞到：同一波（一排墙）只算一次。燃料最多扣 `fuel_max_loss`，和原来一样；不会失败。
  - 结尾最后一排过去：泛光闪亮、`ship_whoosh` + `engine_boost`、轻晃一下。
  - `--story_auto`：只播两波（一块 + 一排墙），连拉远拉回约 8.8 秒；自动玩挪到通道正中，不会擦边。
- **光晕均匀**（`ship_glow.gd`）：不再分船底 / 上沿 / 两侧，整圈同一个亮度和距离（`REACH` 14 × `reach_scale`），往上往下挪都一样。
- **热光**（`ship_glow.gd` 的 `heat` / `heat_goal` / `hold_goal` / `hot_side`）：
  - 颜色从青绿换成暖红（森林余火、尾焰那组红），推进器那头最亮、照得最远。颜色换的时候缓起缓停，约 0.9 秒。
  - 森林起飞：一直是热光，预热亮到 0.55，离地按竖直速度再往上，悬停收到 0.3，尾焰点着以后慢慢熄。
  - flight1 开头：窗外是 `canopy_fall` / `forest_below` 时，驾驶舱剖面外一圈热光慢慢亮到 0.5，换到别的状态慢慢收掉。
  - 之后船一按速度挪（躲碎石），自动平滑换回青绿。

## 躲碎石时船停在屏幕右边（10-31）

作者：「第一个躲避陨石的游戏，能让飞船置于屏幕右侧吗，现在是屏幕正中间提前量有点不够」。

- 拉远时船一边缩小一边往右平移，停稳时图的中线在屏幕宽度 73%（x = 350，船身约 245..455，右边留 25 像素）。
  做法：`cockpit_room.far_out(k, sec, cx)` 多了参数 `cx`，把缩放的 pivot 往右放，所以缩小和平移走同一条 smootherstep 曲线；拉回时倒着走回中间。
  `cx` 默认 -1，表示留在中间（`cockpit_dash.gd` 冲出去那段不变）。
- 远景里碎石再慢一成（`FAR_SLOW` 0.9）。预告从「擦到船前固定 2 秒」改成「进画面前 1.2 秒（`WARN_OFF`，和原来一样）+ 从屏幕左边飞到船头的时间」。
  所以碎石出生得更远，波次节奏（每波之间隔多久）不变，整段约 43 秒，12 波。
- 碎石从进画面到碰到船头：原来约 0.8 秒，现在 1.65 秒。日志 `COCKPIT debris_steer … lead=` 会打印这个数。
- 跟着船走：泛光、擦边火星、气流线、晨的小声说话本来就是按船的位置画的，不用改。
  提示「↑ ↓ 躲开碎石」挪到船下面。声像：`nav_beep`、撞到、擦边、穿出去都放在船那儿；`debris_pass_r` 放在船尾再往右。
- 剧本参数 `"far_x"`（0.5～0.8）和命令行 `--far_x=` 能改停的位置；0.5 就是原来停在中间。

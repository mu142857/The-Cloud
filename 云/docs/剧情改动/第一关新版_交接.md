## 支线接口（11-02 夜，设计见 `第一关支线_设计.md`）

**支线文件**
- `data/forest_side_*.json` 由森林剧本顶层的 `"include": "res://data/forest_side_"` 自动合进来，按文件名顺序。
- 格式写在共享笔记 `forest-side-schema.md`：
  - 可写 speakers / markers / items / hotspots / scenes / objectives / hints / barter / residents。
  - id 前缀：side-a 用 `sa_`，side-b 用 `sb_`。
- 重名、坏 JSON 都会被 `--story_check` 报成错误。
- 支线文件的 objectives 显示在左上角主目标下面一行：「（可选）…」，暗一点。
- 支线点自动带 `_side` 标记。自动玩默认先做支线、再推进主线（F8 节拍「支线·…」接着玩才走得到）；`--main_only` 只走主线。屏幕边上的主线小箭头不指向支线点。
- 支线物品每一章都补进物品表（`chapter_flow.register_side_items`），直接进后面章节也认得。

**两个窗口**（flag `c1_side_open`，支线点都写 `"need": ["c1_side_open"]`）
- **窗口一**：`c1_exit` 出门，鹿在门口说完话 → 设上；倒木推开、塌陷口搭上木板桥（旧路 → 雾 → 空地走得通）。
  - 跟鹿说话（`c1_deer_go`）= 出发去兔子那儿，同时清掉 `c1_side_open`。
- **窗口二**：`c1_fixed` 时再设上，到起飞都开着。
  - 修好以后从树屋门出去（`c1_out2`），先站在门口，鹿等着。跟鹿说话（`c1_go_home`）= 回飞船、道别。
  - 也可以自己走回飞船，点飞船（`c1_home_alone`），鹿会跑过来道别。
- 旧路段和树屋段之间：布条（`c1_to_trees`）、回旧路（`c1_to_road`）两个点，用的是旧的淡入淡出 scene（`to_treehouse` / `to_road`）。

**飞行一的燃料**
- 物品加了 `fuel_kind`：unrelated（地板、兔子皮毛、告白信，加上支线的无关燃料）/ personal（玩具熊、全家福）/ none。
- 改航线时的需要量 = 现在的燃料 + 背包里所有 unrelated 的燃烧值 + 100（`{"do": "fuel", "need_held": "unrelated", "plus": 100}`）。
- `burn_held kind unrelated` 先把它们全烧掉，烧完一定还差 100，所以永远得烧一件私人物品。
- 实测（headless）：
  - 没做支线：需要 575，烧完 475/575，放玩具熊补满。
  - 加两件各 70 的测试燃料：需要 715，烧完 615/715，放玩具熊补满；不能烧的那件留在背包里。

**F8 节拍页**
- 两个窗口：「支线窗口一（鹿在门口等）」「支线窗口二（修好以后）」。
- 每条支线一个入口，跳到「这条支线刚做完」：大嘴鸟、坡地蹄印、老松树的松脂、油灯送回小屋、收音机送回小吃棚、路标送回空地。
- 跳到支线的 flag 时，所有支线点都能用。所以送还三件（先在树屋拿、再送过去）这种两步的也跳得过去。

**支线文件已经合进来**：`forest_side_a.json`（ch1-repair）、`forest_side_b.json`（ch1-dance），森林一共 295 个 scene。

**实测**（headless）
- 主线：`--story_auto --main_only --story_chain`，没做支线，需要 575，烧完 475/575。
- 全部支线：`--story_auto --story_chain`，做完六条支线，需要 655，烧完 555/655。松脂拿去点灯了，所以不在背包里；钥匙、鹿角布条不能烧，留在背包里。
- 两种情况都放玩具熊补满，都接到了飞行一和后面的章节。
- `--dev_test`：森林 16 个节拍全部 ok。

## 改了什么

**剧本 `data/story_forest.json`**
- 新流程全是 `c1_*`：scene、flag、marker、hotspot、目标、提示。入口是 `hooks.crash = c1_crash`（坠毁动画、晨爬起来以后播）。
- 旧流程没删。89 个旧 hotspot 都标了 `"retired": true`（不加载），旧目标和提示的 `not` 里加了 `c1_crashed`。所以旧 scene 都还在，只是不会触发了。F8「探索」的进出口照旧能用旧点。
- 顶层新增的几项：
  - `hide_props`：开场行李、三样材料、地上的发光木头一开始就藏起来。
  - `bag_lock`：背包拿回来以前，背包按钮和 Tab 都不出来；鹿送的玩具熊先拿在手上。
  - `one_way`：拿回背包以后，左墙挪到 `c1_bag_wall`（470）；往回走会浮出「你的直觉告诉你……」。修好飞船以后解除。
  - `item_views`：在背包里选大象的画，按「查看」进 `c1_drawing`。
- 新物件 `c1_bag`：从 `luggage.png` 里截出中间那只背包（15,5 起 15×13），没有新画图。

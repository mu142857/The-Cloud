# 第二章（河流）可玩性设计（11-04）

作者：「第二关的小游戏和支线都不如第一关有趣」「还有整个第二关的可玩性」。

第一关好玩的地方：每一段都是一个短动作，不是一段对话（起身 QTE、Shift 奔跑、跟着箭头跳舞、敲管子盖盖子、接松脂、调收音机、刹路标）；开头一个离谱的选项会改变后面的台词（「妈妈」）；晨几乎不说话，笑点在三选一（正常 / 真诚 / 离谱）里。

第二章照这个改：

- 每一步给玩家一个**动词**，一个笑点，一个「之后会变」。
- 晨不说话，只在选项里开口。水下谁都不说话。
- 每个小游戏都 **≤ 60 秒**，**不会输**（失败几次自己放水），**跳节拍和自动玩都能过**（`run / auto / ff / check`）。
- 面板按 `overlay_layout.gd` 的规矩摆：面板在对话那一带上面，按键提示在面板上面一行，左上角目标让开。

## 每个小游戏怎么玩、怎么放水

### `river_valve`：旧街水闸（替掉 `river_sluice`）

- **画面**：左边大铁闸轮，右边压力表，下面一截冒泡的管子。表盘上是泥芙的画：小鱼、鞋、茶壶、鲸鱼。
- **玩法**：按住转轮子，指针往上走。离这道闸要的位置越远，管子冒泡越凶、咕噜越响；到了那一点，泡泡停下、管子安静，这时候松手。松早了不要紧，接着按；转过头（泡泡又冒起来）才会「噗」一声弹回去。三道闸一道比一道高（鞋 → 茶壶 → 快到鲸鱼）。
- **放水**：失败 3 次，泥芙用粉笔在表盘上圈出位置；失败 5 次，她帮你转好。

### `river_borrowed`：水下仓库（替掉 `river_warehouse`）

- **画面**：五只贴着标签的箱子在水里漂，各漂各的，会互相超过。左上角是泥芙和三个「记得」泡泡。
- **玩法**：←→ 选一只箱子，空格打开。
  - 泡泡每 4 秒破一个。泡泡还在时，标签是正常的字（「播放器零件」「浮筒」）。
  - 三个泡泡都破了，标签就变回她的暗号（「圆圆的」「不要煮」「好像是我的」「别问」），她低头翻本子，2.4 秒后泡泡和字一起回来。
  - 要找两样：读取头、浮筒密封圈。开错一只，翻出一样离谱的东西。
- **放水**：开错 3 次，她不再忘，还会伸手指着对的那只。
- 没有气量表、没有倒计时。做完以后剧本把柜子、家具、内门设成「开了」，接着演泄水门记录。

### `river_thread`：修飞机

- **画面**：一截管子、一只六角接头、印着的「拧紧 →」，还有泥芙的便条「反方向！」。
- **玩法**：←→（或按住鼠标左 / 右半边）拧。往右（照箭头）接头往外退、嘶嘶冒气；往左才拧得进去。拧进 2.5 圈就「咔」一声做完。
- **放水**：往右拧到脱扣 3 次，泥芙握着晨的手往左拧。

### `river_guestbook`：来客册（可选）

- **玩法**：←→ 交替按（或鼠标左右晃）扇风，水渍一块块缩小，名单一行行露出来。
- **放水**：6 秒没扇，泥芙凑过来吹，页面自己慢慢干。

### `river_cook`：鼠妈看锅（可选，第一次在市集见到她的时候）

- **玩法**：汤面先有一圈涟漪慢慢收紧，收到最小时大泡「咕嘟」破掉，在那一下按空格，把吊着的东西放进去。前后差 0.2 秒都算对。
- **放水**：按错 3 次，「行了行了，锅不挑」，之后什么时候按都算对。

### `river_bridge_view`：南桥（保留，加一段）

找到机位、取景框对上的那一刻，一只大象的灰影从左边慢慢走到对的桥洞底下，再淡出去。影子画在世界里，在晨身后，一步一顿。接下来问「它是从哪个桥洞过去的」，答案就是刚才看到的那个。

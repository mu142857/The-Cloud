# 木星森林：游戏相对剧情姐原稿的改动

对照的两边：
- 原稿：剧情姐合订稿 docx 的「木星森林」一节（开头到「离开森林」之前）。
- 游戏：`data/story_forest.json`，加上 `data/items.json`、`data/phone.json`、`scripts/level_forest.gd`（开场、发光木头）。

说明：
- 括号里是 scene id 或 hotspot id。
- 「补写」= 剧本里标了 `"added": true`，游戏里用蓝色显示，等剧情姐审。
- 有不少台词没标 added，但和 docx 字面不同。它们来自剧情姐 10-29 的对白表（口语版），按 `docs/forest_chapter.md` 第六版的规矩「台词以对白表为准」。意思没变的不列。

## 一、故事回顾（按原稿）

1. 晨的飞机坠进木星森林。树林深处传来一声低鸣，远处的树冠一排排摇动。晨摸出朋友画的大象，朝雾里喊「等一下！」，没人应。
2. 晨捡到发光木头，燃烧值 10 → 60，要到 200 才能起飞。翻行李：日记第一页写着「我一定要找到大象，因为」，后面空着；夹着一页回忆：朋友说过，哪天不联系了，就去找云层里的大象，找到就能再收到她的消息。
3. 燃料凑够了，推进器又坏了。鹿出现了，看到画说「大象啊，旧路那边有」，带晨走旧路，去找会修东西的弥洛。
4. 旧路上，鹿讲那些废掉的旧地方，晨只记和大象有关的事。两人搬开倒木，在雾里听鹿角敲树找路。鹿说的大象越来越含糊：鼻子很长 → 离得太远 → 只看到背影。
5. 树屋：弥洛嘴硬心软。她嫌晨买便宜燃料，教晨听管道找漏气，修好推进器，顺手修好音乐盒。她的留声机一直卡着，有新零件也不肯换。屋里摆满主人搬走了的旧东西。
6. 三个人去送水泵，经过空屋和商店。看得出弥洛一直在等一个走掉的朋友。
7. 坡地：鹿承认自己没亲眼见过大象，是妈妈讲给它的。晨想起朋友说过「我得顺着你说，你才肯听，对吗？」，划掉了日记里的「亲眼见过」。雾里又响起一声低鸣。
8. 回到树屋，弥洛换好了留声机的零件，讲了她和朋友吵架、朋友去了河流城市。她给晨透明种子和明信片，把自己的号码存进晨的通讯器。鹿送晨回飞机，晨装好零件，改正日记。

## 二、改动清单（按剧情顺序）

### 开场：黑屏、标题、坠毁

1. 【改了】原稿：黑屏，风从左边吹过，右边有枯枝被踩断；屏幕中央写「建议佩戴耳机。留意声音，它会帮助你辨认方向。」 → 游戏里：黑屏只有耳机图标和「建议佩戴耳机游玩」，没有后半句。离开这一屏以后是雨声和远雷，没有「左边风、右边枯枝」的方向声。（`level_forest.gd` `_enter_headphones` / `_leave_headphones`）
2. 【删了】原稿：右下角「选项」里有「声音方向提示」。 → 游戏的设置里有语言、总音量 / 音乐 / 音效、特效、全屏，没有「声音方向提示」。（见第三部分）
3. 一致：点开始，天空闪三次，雷声越来越近，冒烟的飞机从右边冲进画面，撞进地面。
4. 【改了】原稿：晨推开舱门，扶着机身爬出来。 → 游戏里：晨被甩出舱外，摔在地上，再爬起来。（坠毁动画 `_chen_thrown`，开场动画本来就这么做的）
5. 【加了】晨爬起来先说两句：「啊……糟糕。早知道就买保险了。」「行，你先歇着，我还没打算让你报废呢」。原稿没有这两句。（intro）
6. 【删了】原稿开场的低鸣响两次：第一次晨抬头；第二次在晨急着展开画、纸角勾在一起的时候。 → 游戏里开场只响一次。翻两遍口袋、纸角勾住这些小动作也没有，只有一个「摸衣袋」的动作。（intro，`elephant_call` variant 1）
7. 【加了】拿出画时，屏幕中间展开画的特写；然后切到坠毁现场的树冠，被撞出的缺口正好对上画上大象背部的弧线；晨说「……刚才撞上的，是这个？」。（intro 的 `drawing_closeup` / `treeline_match`。原因：剧情姐的建议，要坠毁后尽快给大象一个异常的迹象。这句按她的原句处理）
8. 【加了】坠毁现场多一个可以再看的「树冠缺口」，补写 4 句（「那道缺口的弧，和画上一样。」「……也可能，只是我撞的。」，起飞前再看是「缺口还在。」「下次来，也许就长好了。」）。（treeline_gap / treeline_gap_late）
9. 一致：「是你说的那个吗？」、朝雾里喊「等一下！」、回头「偏偏这时候坏，你可真会挑。」、零件装不上、若无其事拍拍机身。
10. 【改了】原稿：日记首页和回忆页是恢复操作以后，玩家自己翻背包看的；晨抹平被撞皱的纸角，在墨点上停一会儿，压住纸边想了想，没补日期。 → 游戏里：开场 intro 自动弹出日记首页和两条回忆（之后背包里也能再翻）。晨的这几个小动作没有。
11. 【改了】回忆页原稿写「ta说到时候就知道了」「ta笑了一下」 → 游戏里是「她说」「她笑了一下」。（intro。原因：失联的朋友统一用「她」）

### 发光木头和燃料

12. 一致：走近发光木头，上下出现黑边，晨自动拾取；「有这个了，你总该动一下了吧」；燃烧值 10 → 60；「启动所需：200」；「行，那就再找一点」。
13. 【改了】顺序：原稿里木头紧接在坠毁之后，「恢复操作后」才翻行李。 → 游戏里坠毁现场往左挪了一屏（10-30），行李就在飞机旁，发光木头在右边约 7 秒路的空林子以外。玩家多半先翻行李，再捡木头。（markers `luggage` -770 / `wood` 372）
14. 【玩法】原稿只写「在坠毁现场收集普通材料」。游戏里是三样：金属碎片 50、树脂 40、干枝 50，走过去就自动捡，不用停下；10 + 50 + 50 + 40 + 50 = 200。每样捡起来晨冒一句小气泡。（scrap / resin / branch）
15. 【删了】原稿：收集材料时，远处可以再次听见低鸣，画面停在雾和树冠上。 → 游戏里没有这一声。整章只有开场和坡地两声。
16. 【加了】屏幕左上角的「当前目标」跟着主线变：找燃料 → 试着启动飞机 → 跟着鹿 → 找会修的人 → 找松脂、弹簧、阀门 → 回树屋 → 修好推进器 → 送水泵 → 跟上弥洛 → 跟鹿上坡地 → 回树屋 → 出门，回飞机 → 回飞机。全部补写。（顶层 `objectives`）
17. 【加了】玩家 20 秒不推进主线，晨会自言自语一句提示，比如「罐子还空着。」「门口那只鹿，也许知道。」。每个阶段 2～3 句，全部补写。（顶层 `hints`）
18. 【加了】燃料不够时点飞机：「燃料还不够。」（补写）「再撑一趟吧，就一趟」；遇到鹿以后点飞机：「推进器坏了」「先跟鹿去找会修的。」（补写）。（wreck_wait / wreck_broken）

### 行李里的纪念品

19. 【加了】翻行李时晨冒三句小气泡：「好，行李全摔出来了，都不用我翻了」「又是这个站，这名字我闭着眼都能写了」（通勤卡）「后面写什么呢，每次都卡在这儿」（日记）。音乐盒那句「在家唱得好好的，怎么一出来就哑了」和拍两下、没拍好再拍两下，是原稿的。（luggage）
20. 【加了】行李里多一件「物种查询结果」：「未找到符合描述的物种」，晨在旁边写了个很小的「再查」。原稿这一版没有，是旧稿留下的；飞行段和结局还在用。（items.json `species_query`）
21. 【加了】通讯器打开是朋友的聊天窗口，里面有 19 条补写的旧聊天：3 月找下午晒得到太阳的车厢座位、音乐盒卡了朋友说「别拍它」、4 月 2 日那次争执（「说了。你没在听。」「嗯。周六再说吧。」）、之后只有晨一个人发，最后一条「明天出发了。」是出发前一天。原稿只写「晨发出的最后一条消息后面一直空着」，按灭屏幕收进衣袋。（`data/phone.json`，全部补写）
22. 【删了】音乐盒的说明少了「朋友抢在前面唱，唱完自己也笑」。「如今再听到这里，晨还是会等一下，像等旁边的人先出声」挪到了修好以后的说明里。（items.json `music_box` 的 desc / desc_fixed）
23. 一致：大象的画、通勤卡、母星照片、蓝色石头、地图、日记的说明都是原稿原句。

### 启动失败，遇见鹿

24. 【改了】原稿：燃烧值一到 200，屏幕随即弹出「推进器损坏」。 → 游戏里：到 200 时晨说「够了，回飞机那边试试」，玩家要走回飞机点一下，才弹出「推进器损坏」。另外多一件物品「坏掉的推进器零件」，后来交给弥洛。（fuel_full → launch_fail）

### 旧路

29. 【改了】原稿：鹿自己介绍水源、矿石和树屋，晨的笔停着，一说到旧路以前有大脚印，笔才动。 → 游戏里改成晨先问「附近有水吗？」，鹿说「前头往左，有条小溪，水甜」；没有矿石；说到脚印，晨追问「脚印？」并记进日记。（road_1，补写 4 句和 1 条日记）
30. 【改了】原稿里「鼻子很长，左边的耳朵会动，走过去的时候树枝都在晃」要到坡地才由晨念出来，前面只概括说鹿的说法在变。 → 游戏里在 road_1 就让晨问「你见的那头大象，长什么样？」，鹿说出这三点，晨问「这些你都亲眼见过？」「咱见过」，日记记下「鹿亲眼见过大象」。（road_1，补写 3 句和 1 条日记。原因：坡地那句「这些也是你编的？」要有前文）之后的变化和原稿一样：倒木那里「隔得远」（log_push），树屋外「就一个背影」（treehouse_outside）。
31. 一致：小吃棚。鹿走慢一点，「这儿以前卖吃的」、角勾着人家的布、忘了卖什么、「反正好吃」、「说不定大象以前也从这儿走过呢」，晨问什么时候；页角画顶棚布的鹿，「还没画好」，偷偷加一对过大的角。（stall_intro）
32. 【加了】小吃棚可以再看：晨说家乡车站下雨也这么挤（stall_look）；和鹿闲聊歪树被雷劈过、鹿在树下躲过雨（deer_chat_stall，补写 2 句）。
33. 【加了】旧路上新加一间「路边的小屋」，在小吃棚和倒木之间。它是送还油灯的地方，晨能看一眼窗台。（road_house）
34. 一致：倒木。「这边近」、晨问多久没人走了、鹿让晨拖下面轻的树枝、「这几根我来就行」、「拿得动吗？分两趟呗」。
35. 【玩法】倒木：两根树枝两个点，点一下拖开一根，拖完鹿顶开倒木。原稿里晨换两次手、趁鹿转头悄悄放下最上面那根，游戏里只剩一声树枝掉落的音效。点倒木本身，晨说「这根太重了」。另加一条日记「问起旧路，鹿忙着让我搬树枝，回头再问。」，鹿补一句「大的咱来顶。」。（log_intro / branch_a_drag / branches_done）
36. 【玩法】雾里找路：原稿只写跟着蹄声和鹿角敲树两下走，第一次跟错后晨收起日记认真看路。 → 游戏里做成轻解谜：鹿走进雾里慢慢淡掉；鹿角敲树声有左右方向；同时有画面线索：地上的蹄印、树枝上的布条；有一根没布条的「错」树枝；走到塌陷口晨自己停下。第一次跟错记日记「雾里跟错了一次。先听，再走。」（补写）。还可以举起发光木头照亮雾（fog_wood_light）。在布条那里互动就到树屋。（fog_intro / fog_call / hoofprints / fog_branch / hollow_edge / cloth_enter。原因：不戴耳机也要能玩，不能有失败）
37. 【改了】原稿小游戏写「清理林间旧路，同时收集修船材料」，到了树屋「晨把材料放在门口」。 → 游戏里旧路上不收修船材料。修船的东西改成弥洛诊断以后再去找（见第 46 条）。

### 三样零件（游戏插进来的中段）

46. 【加了】原稿「晨立刻放下，说要留下帮忙」之前，游戏插了一段：弥洛说想飞起来还差三样东西：松脂、弹簧、阀门零件，给晨一个装松脂的小罐子，让晨去问门口的鹿（补写 2 句和 1 条日记）。三样先找哪样都行，这段时间整片森林随便走。鹿不带路，在树屋门口等，问它会给方向提示（deer_hint_*）。（原因：作者 10-29 嫌太像视觉小说，要提高自由度，`docs/forest_chapter.md` 第三版 B）

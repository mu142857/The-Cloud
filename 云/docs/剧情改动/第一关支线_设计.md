# 第一关支线：设计（11-02 夜）

作者玩完新第一关：「这才叫游戏嘛，体验相当好」。要求：

- 旧的支线（树脂、小屋、大嘴鸟……）**不删，改成可选**。不强迫做，主线照样走得通。只走主线的人大概只用一半时间。
- 每条支线最好都是**一个有趣的小游戏**。
- 有趣的地方都学**本2兔**：比如「我是你的母亲，还不过来孝敬我」这种谁也想不到的荒谬选项，以及按妈妈 / 孩子关系变的称呼和回应。

## 什么时候能做

- **窗口一**：从弥洛家出门（`c1_need_wood`）到跟鹿去兔子那儿之前。出门以后鹿不再立刻八比特转场，而是在树屋门口等。**跟鹿说话 = 出发去兔子那儿**。左上角主目标照旧，支线另起一行，标「（可选）」。
- **窗口二**：修好飞船（`c1_fixed`）以后、起飞以前。这时左墙已经解除。
- 支线地点用旧地图上现成的位置：旧路、小吃棚、雾、空地、空屋、商店、老松、坡地。连不起来的地方用现成的淡入淡出（布条那种）。

## 写法（所有支线通用）

- **晨基本不说话**。有趣的话放在选项里。每个节点最多 2～3 句，`"added": true`。
- 每条支线至少有**一个本2兔式的荒谬选项**：三个选项里一个正常、一个真诚、一个离谱。离谱的那个对方要有反应，还要有后果（比如之后的称呼变了）。
- 能接上**妈妈 / 孩子**（`c1_mom` / `c1_child`）的地方都接。
- 做不好也不会输：小游戏失败几次就自动过，或者对方吐槽一句再来。

## 支线

| # | 支线 | 小游戏 | 荒谬的一下 | 奖励 |
|---|---|---|---|---|
| 1 | **老松树的松脂**（`pine`） | **接松脂**：按住让松脂往罐里滴，越滴越快，到线就松手。滴满了、溢出来，罐子会黏在晨手上甩不掉（再来一次） | 老松树开口：「又来放血？」选项：「我是来献血的」/「对不起，我需要你的眼泪」/ mom 线「我是你的母亲」（松树：「……我四百岁了。」） | 一罐松脂（无关燃料） |
| 2a | **收音机送回小吃棚**（`stall`） | **调台**：左右拧旋钮找台，中间会串到几个怪台（已经没有了的星球的天气预报、鹿在唱歌……），最后调到小吃棚以前的叫卖声 | 串到的台里有一个在播「失物招领：一位自称是鹿的母亲的人」 | 小吃棚的旧菜单（无关燃料） |
| 2b | **路标送回空地**（`glade_sign_base`） | **按停**：路标一直自己转，按一下停住，要停在指向空地中心的那一格 | 好几次停下来它都指着晨。旁白：「它好像觉得你就是路。」选项：「我不是路」/「那就跟我走吧」（路标跟着晨跳一段，然后被插回去） | — |
| 2c | **油灯送回小屋**（`empty_house`） | **点灯**：灯没油。用支线 1 的松脂（或别的东西）当油，点着以后墙上出现以前住户的影子，他们在挥手（手影戏，跟着影子做对一个手势） | 影子里有一个也在找背包 | 小屋的钥匙（不能烧的纪念品） |
| 3 | **大嘴鸟**（`glade_toucan`） | **接果子**：大嘴鸟把果子抛过来，左右移动去接；接到够数，它就肯交换 | 它也要晨叫它妈妈。选项：「妈妈」/「不」/「你嘴太大了，当不了妈妈」（它生气地把嘴合上，合了三秒才合拢） | 大嘴鸟的尾羽（无关燃料） |
| 4 | **坡地·鹿的妈妈**（`slope`） | **跟蹄印**：雾里地上一串蹄印，按顺序踩对；走岔了雾会变浓、轻轻把人送回来 | 鹿的坦白按关系变。mom 线：「妈妈，其实咱以前真的有过一个妈妈。」child 线：「孩子，其实咱也是被人捡回来的。」然后是旧稿里「咱娘指着雾里说那边有大象」，压成三句 | 鹿角上的布条（不能烧的纪念品） |

旧稿的东西尽量复用：画、道具、旧 scene 里好的句子（压缩后用）、`barter.gd`。

## 燃料不能被支线破坏

做了支线会多出几件无关燃料。飞行一的燃料需求要**按实际持有的无关燃料算**：需求 = 持有的无关燃料总和 + 约 100。这样不管做了几条支线，最后还是得烧一件私人物品（玩具熊 / 全家福）。

## 谁做什么

- **ch1-story**（串联，管 `story_forest.json`、`story_runner.gd`、`story_world.gd`、`level_forest.gd`、`story_flight1.json`、`items.json`）：
  - 剧本支持多个文件：加 `data/forest_side_*.json`，把 scenes、hotspots、objectives、markers、items 合进来。
  - 两个窗口、「（可选）」目标行、旧区域重新开放、飞行一按实际持有算需求。
  - F8 入口、`story_check`、自动通关。
- **side-a**：支线 1、2a、2b、2c。小游戏脚本 + `data/forest_side_a.json`。
- **side-b**：支线 3、4。小游戏脚本 + `data/forest_side_b.json`。
- 新物品写进各自 json 的 `items`，不改 `items.json`。

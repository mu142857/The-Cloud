# 《云》剧情简版：晨都做了什么

依据剧情姐 10-30 合订稿和现在游戏里的剧本，只写晨做了什么、遇到了谁。原文和台词以剧情姐的为准。

**一句话**：晨要找朋友画过的那头大象，飞船一路坏一路修，每到一个星球就离大象更近一点。

## 森林（木星）

1. **坠毁**：飞船掉进森林。树林深处传来一声低鸣，远处的树冠一排排摇动，像有个很大的东西在雾后面走过。
2. **捡东西**：晨翻行李，找到大象的画、通讯器和几件纪念品。画上大象背部的弧线，正好对上飞船撞断的那排树冠。然后捡发光木头和材料，凑够燃料。
3. **启动失败**：推进器是坏的。鹿出现了，看到画说「大象啊，旧路那边有」，带晨走旧路。
4. **旧路**：鹿在前面带路。晨挪开树枝让倒木滚走，在雾里跟着蹄印和布条找路，到了树屋。
5. **树屋**：修理工弥洛能修推进器，但要晨自己去找三样零件：松脂、弹簧、阀门，先找哪样都行。
   可选：把弥洛屋里修好的旧东西送回给搬走的那几户人家。
6. **修好推进器**：递对工具，听管道找出漏气的那一段。弥洛还帮晨修好了音乐盒。
7. **送水泵**：三个人一起去空屋和商店。从这里看得出，弥洛一直在等一个走掉的人。
8. **坡地**：鹿坦白：它没亲眼见过大象，是妈妈讲的，讲多了就说成了「见过」。晨划掉日记里的「亲眼见过」。雾里又响了一次低鸣。
9. **告别弥洛**：弥洛讲了她等的那个人。她给晨一颗种子、一张「河流城市」的明信片，又把自己的号码存进晨的通讯器。
10. **起飞**：晨回到飞船，装好零件，起飞。

## 飞行一（驾驶舱）

1. **碎石带**：上下躲飞来的石头。
2. **漏气**：机身右边漏气，晨找到漏气的地方，用弥洛给的工具拧好。
3. **烧纪念品**：燃料不够绕路，必须烧掉一件纪念品：蓝色石头或通勤卡，二选一。
4. **通讯器**：弥洛发来消息。晨想给朋友发「快找到了」，打了又删掉。
5. **迫降**：飞到河流星，飞船迫降，卡进一条窄水道。

## 河流篇（妮芙的三分钟）

1. **河岸**：晨遇见妮芙（长着鲸鱼尾的女孩），帮她顺着水流打捞掉进河里的东西，顺便捞到修船零件。老人阿汀帮忙把飞船拖上岸晾干。
2. **妮芙家**：沙漏每漏完一次，妮芙就会忘掉刚发生的事，全靠小本子记着。晨拿出明信片，上面正是她家以前的窗子。来客册里记着，弥洛等的那个人来过这里。
3. **影像盒**：晨给妮芙看大象的画，她翻出一盒「南桥拍到的大动物」影像。大象的鼻子刚露出来画面就卡住了。晨连按了几下，读取头松了，影像放不了了。
4. **找读取头**：读取头在水下仓库。晨先去高处市集借呼吸装置，再去旧街调三道水闸，让台阶露出水面，然后下水进仓库，找到读取头。
5. **真相**：仓库里有一份泄水门记录。当年是妮芙自己开的闸，她知道这样一来，自己的收藏会被水泡掉，还是开了，为了不让别处被淹。回到岸上，阿汀把当年的事讲了出来。
6. **修好影像**：晨看清了大象：它的耳朵缺了一角，正在桥边扯缆绳。晨第一次听到了完整的低鸣。来客册也晾干了：弥洛等的那个人后来坐补给船去了云层星，还给弥洛寄过信，只是信没送到，那只邮箱被水冲走了。
7. **南桥**：晨对照影像找到当时拍摄的位置，找到了大象走过的水道、脚印和毛。
8. **货台**：晨把墙上的编号牌和旧装卸记录对上，翻到一张照片：有人正用食物引大象走上一艘去云层星的运输船。晨记下了船号。
9. **告别妮芙**：回来的路上，妮芙找到她以前小船上的铜铃，送给晨挂在飞船里。晨修好飞船，和妮芙告别。妮芙把影像送给晨，让晨找到大象以后回来写给她看。晨起飞，去云层星。

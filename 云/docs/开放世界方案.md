# 开放世界方案（10-31 草稿，作者看完再定做不做、什么时候做）

**一句话**：主线还是一个大故事，一条线走到底。每颗主星旁边挂一颗小卫星，可去可不去，没有主角也照样有自己的日子。NPC 之间能以物易物，换来换去会在结局和尾声里留下痕迹。燃料还是「烧东西换航程」那一套，只是能烧的东西来源多了。

---

## 1. 两颗卫星

**两颗都遵守的规矩**
- 离主星近，**来回不耗燃料**。
- 驾驶舱的导航（`cockpit_nav`，终章已经有）多一个「去卫星」选项：起飞和降落的过场复用森林起飞那段，加河岸降落的黑场，不进飞行段。
- 什么时候都能去，主线不会把人锁在卫星上。
- 卫星上没有主线 flag，只有自己的支线 flag 和交换 flag。

### 竹林星（森林旁边）

- **生态**：竹子顺着风向一排排长，一夜长一节。起风的时候整片竹林一起响，每片林子的音高不一样。林下住着把竹筒当家的小蜗牛（竹筒蜗牛），竹子长高了，它们就得搬到新的一节去。这颗星的日子按风过：哪天风大，哪天就搬家。
- **有什么**：一片竹林（两屏宽）、一间竹筒屋、笋田、一位刻竹片的老人（以物易物 NPC）。
- **支线**：
  - 帮蜗牛搬家（轻解谜）：听哪一排竹子的声音不对，把竹筒挪过去。复用河流篇水闸「听哪边还在冒泡」的那套听声判断。
  - 刻竹片：拿森林的东西换一片刻着字的竹片，竹片终章能烧。
- **复用**：
  - 美术：森林的视差层和地面公式（`forest_art.py`），树干换成细竹竿，配色用森林绿、青绿（作者定过：不用蓝）；
  - 系统：`npc_generic`、`barter`、hotspot、`mechanic`、`residents`。

### 红树林卫星（河流旁边）

- **生态**：每次来潮位都不一样。退潮时树根之间露出一条路，涨潮时路就淹了。根缝里住着招潮蟹、弹涂鱼和寄居蟹，寄居蟹一直在找合适的壳。这颗星的日子按潮水过。
- **有什么**：一片红树林河湾（一屏半）、潮汐刻度柱、寄居蟹的「壳市」（以物易物）。
- **支线**：
  - 看潮水走路（轻解谜）：退潮时能走到对面，涨潮时只能看。复用旧街的水位和 `water` 系统、仓库的水下房间。
  - 寄居蟹换壳链：给它一个空罐子，它把旧壳给下一只。链的最后一只蟹送晨一枚贝壳，终章能烧。
- **复用**：
  - 美术：河岸月夜的色板和水面 shader（`river_water` / `moonpath`）；
  - 系统：水位 states、`underwater` 房间、`barter`、`residents`。

## 2. 燃料：不加新玩法，只让「能烧的东西」来源多一点

现在的燃料玩法：飞行一和终章都是驾驶舱里把东西放进转化装置、看燃料表；飞行一点漏气处，终章碎石带「黑窗听航道」。动手但不会输，这一点保持。

**加的只有三条，界面全复用托板**：
1. **卫星上能捡材料**：竹林星有干竹节，红树林有晒干的根须。材料放在托板上和纪念品摆一起，烧材料不用心疼。
2. **材料有上限**（推荐最多抵 40～60）。到终章燃料柜，至少还是要烧一件纪念品。「还剩下什么」这个主题不能被材料冲掉。
3. **换来的东西也能烧**：尾羽、鸟哨、竹片、贝壳。玩家会碰到一个新问题：「这是别人送我的，烧不烧？」这和烧纪念品是同一种难受，不算新玩法。

**主星之间才耗燃料**：森林到河流是飞行一，河流到云层是终章，各段原样不动。卫星只影响托板上多了几件可放的东西。

## 3. 以物易物网络

- **现在**：大嘴鸟（森林）、料理鼠妈（市集），机制做好了，交换表草稿在 `docs/以物易物交换表.md`。
- **扩成网**：每颗星一个收东西的人，东西沿着航线流动。

```
森林  大嘴鸟 ──尾羽──▶ 河流  鼠妈 ──菜谱
  │                         │
竹林星  刻竹老人 ◀──竹片───┘ 红树林  寄居蟹（换壳链）
```

- **成就**：现在只记 flag（`barter_*`），「全剧终」卡下面列出拿到的几个。以后要单独的成就页再做。
- **蝴蝶效应落在三个地方**，都用 `if` 加在已有段落里，不改剧情姐原句：
  1. 终章燃料柜里多一件、少一件或换一件；
  2. 结局一到四里多一句对白；
  3. 尾声回访时，那个 NPC 那里多一个小变化，比如鼠妈的灶一直没熄、大嘴鸟的树桩上多了一样亮东西。

## 5. 要作者拍板的（附推荐）

1. **卫星什么时候能去？** 推荐：降落在主星以后随时能去，起飞去下一颗主星前最后能去一次。玩家不会错过，也不会卡在卫星上。
2. **卫星做成一个房间还是几个？** 推荐：各一个房间（一屏半到两屏宽）。小、能一眼看完，像「顺路去看看」。
3. **材料能抵多少燃料？** 推荐：最多抵 40～60。终章至少烧一件纪念品，主题不能被材料冲掉。
4. **成就有没有界面？** 推荐：先列在「全剧终」卡下面，S 就能做完。单独的成就页留到截止以后。
5. **卫星上要不要有主角的回忆或日记？** 推荐：不要。卫星就是「没有晨也照样过日子」的地方。晨只是路过，顶多在日记里写一行看到了什么。
6. **飞去卫星要不要一段短飞行？** 推荐：不要。作者说过「飞船破坏氛围」，也讨厌每章换玩法，直接用起飞和降落过场。

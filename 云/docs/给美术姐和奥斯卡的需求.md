# 给美术姐和奥斯卡的需求（10-30 夜整理）

现在游戏里，缺图的动作都退回待机，缺图的角色先用 agent 画的占位图，剧情照常播，什么都不会卡。下面按「先画哪个最值」排了顺序。

规格（和晨一致）：一格 40×52（晨按奥斯卡现有的格子），**朝右画**（朝左引擎自动翻转），脚底中点对齐格子底边，背景透明，像素原大不放大。帧时长画师自己定（引擎保留画师给的时长）。

---

## 一、奥斯卡：晨的动作

剧本里给晨写了 100 多个动作名（「拿着盘子」「翻到那一页」「拿远一点看」……），不可能全画。**画下面这 16 个就能覆盖几乎全部**：引擎把相近的动作名都指到同一个动画上（右列是会用到它的剧本动作）。

### 妮芙（鲸鱼壳）

作者定了：妮芙全程用美术组那张鲸鱼壳动图（岸上悬浮、水下游）。剧本里给她写了很多小动作，现在都退回这张动图，能播，不影响。如果美术组有余力，**在鲸鱼壳里**补这几个最能出表情的（同样的壳、同样的尺寸，只改她本人）：

1. 低头写小本子（她的招牌动作，剧本里出现 20 多次）
2. 点头
3. 吓一跳、尾巴翘起来（原稿：「低鸣第一次完整响起时，她吓得尾巴抬起来」）
4. 挥手（告别、岸边送晨）
5. 笑
